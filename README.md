# MFT Orderflow Research

## Research Question
When does aggressive orderflow fail to produce a proportional
price response, and does this contain predictive information
about subsequent NQ futures returns?

## Dataset
Databento GLBX.MDP3
Instrument: NQ Futures
Schema: Trades

## Project Structure
- data/: Raw and processed datasets
- notebooks/: Research notebooks
- src/: Reusable Python modules
- figures/: Research visualizations
- results/: Statistical and modeling results
